# TaskbarPopup

Windows 11 任务栏增强：窗口最大化时藏起任务栏、让窗口铺满整块屏幕；长按 Win 弹出一个液态玻璃风格的迷你任务栏。托盘常驻，单个 exe，不用装运行库。

## 功能

- **最大化时隐藏任务栏**：窗口一最大化，任务栏就滑下去，窗口同时铺满整块屏幕；把它还原、最小化或关掉，任务栏再滑回来。最大化的窗口还在后面时，在上面打开别的窗口，任务栏也继续藏着。
  - 任务栏藏着时，鼠标移到屏幕底边不会弹出来。要用任务栏就长按 Win，或者按 Win 打开开始菜单、通知中心、托盘溢出区，这时任务栏会临时显示，关掉后再藏回去。
  - 原理：临时打开系统的“自动隐藏任务栏”，任务栏回来时再关掉，不影响你原来的设置。工作区一变，系统会把桌面图标挪一小段，所以只有一块屏幕时，藏任务栏前先给桌面拍一张照片，藏任务栏期间桌面图标也先藏起来，换成这张照片垫在桌面上（这时都被全屏窗口挡着）；回到桌面时看到的是照片，等任务栏回来、图标排回原位显示出来，再撤掉照片，看上去图标一直待在原处，不挪动也不消失一下（照片没拍到时图标会晚一下出现）。万一图标被重排了，也会自动摆回原位。
- **长按 Win 弹出迷你任务栏**：按住 Win 1 秒（时长可改），屏幕底部中央弹出迷你任务栏，前面是固定的应用，后面是其他打开的窗口。固定的应用就是系统任务栏的固定列表，想增减就在系统任务栏上固定 / 取消固定。短按 Win 照常打开开始菜单，Win+E 等组合键也不受影响。
- **音量和亮度**：迷你任务栏最下面一行，左边调音量，右边调它所在那块屏幕的亮度；不需要可以在设置里关掉。
- **窗口缩略图**：鼠标停在窗口图标上，显示这个窗口的实时缩略图。
- **打字筛选**：弹出后直接打字，筛选窗口和固定的应用，还会列出开始菜单里匹配的程序（比如打 calc 找到计算器），回车打开。
- **快捷键**：可以在设置里设一个弹出迷你任务栏的快捷键（再按一次收起），和一个固定小窗口的快捷键：按一下，前台的小窗口（鼠标键的话是鼠标下的窗口）就像双击过一样留在全屏窗口上面，再按一次取消，窗口上方会提示一下。快捷键可以是组合键、单个键（F1、CapsLock、单独的右 Ctrl 这类）或鼠标键（中键、侧键等），每个都能选单按还是长按触发。默认都没设。
- **排除名单**：不想让某个程序最大化时藏任务栏，就在迷你任务栏里右键它的图标，勾选“最大化时不隐藏任务栏”。

## 迷你任务栏操作

| 操作 | 效果 |
| --- | --- |
| 长按 Win / 设好的快捷键 | 弹出 / 收起 |
| 单击图标 | 切换到该窗口，点当前窗口则最小化；没打开的固定应用直接启动 |
| Shift + 单击 | 固定的应用再开一个窗口 |
| 右键图标 / 菜单键 / Shift + F10 | 和系统任务栏差不多的菜单：最近打开的文件（跳转列表），再开一个、以管理员身份运行、打开文件所在的位置；打开的窗口还有还原 / 最小化 / 最大化、勾选“最大化时不隐藏任务栏”、关闭这个窗口或同一程序的全部窗口 |
| 中键单击 / Delete | 关闭窗口（中键点没打开的固定应用则启动它） |
| ← → / Tab | 键盘选择，回车或空格打开，Shift + 回车再开一个窗口 |
| 直接打字 | 筛选（这时空格算输入）；Backspace 删字，Esc 先清空、再按一次收起 |
| 滚轮 | 图标多时左右滚动；在调节条上时调音量 / 亮度 |
| 单击喇叭 | 静音 / 取消静音 |
| 左侧 Windows 图标 | 单击打开开始菜单，右键打开 Win+X 菜单（和右键系统的开始按钮一样） |
| Esc / 点到别处 | 收起 |

图标下的蓝色长条表示当前窗口，短条表示已经打开。外接显示器调亮度需要显示器支持 DDC/CI，并在显示器自己的菜单里打开（多数默认开着），调不了时亮度条是灰的。

## 设置

右键托盘图标 →“设置...”：开关“最大化时隐藏任务栏”、“点全屏窗口时小窗口留在上面”（在浮着的小窗口里双击一下，或者按设好的固定快捷键，之后点全屏窗口它也不会被盖住，没固定的小窗口照常被盖住；要让它下去就最小化它，或者再按一次快捷键）和“长按 Win 弹出”、改长按时长（200 – 5000 毫秒，关掉“长按 Win 弹出”时这一行收起来）、迷你任务栏大小（50 – 200%，在系统缩放的基础上再放大缩小，拖滑块时会弹出迷你任务栏预览）、是否显示固定的应用和音量亮度调节、开机自动启动、自动检查更新、外观（材质选液态玻璃或毛玻璃，颜色选跟随系统、浅色或深色，选了马上能看到效果，迷你任务栏和设置窗口都用这个）、快捷键（点一下右边的框，再按下按键，或者在设置窗口上按鼠标键；单独按一下再松开 Ctrl、Shift、Alt 就录它自己，分左右。框下面选单按还是长按，选长按时下面会多出这个快捷键自己的长按时长（200 – 5000 毫秒），没按够就松开的话这次按键照常生效。设好弹出迷你任务栏的快捷键后，“长按 Win 弹出”会自动关掉，还想要可以再打开。会挡住打字、点击的不让单按：字母、数字、空格、方向键这类要配 Ctrl / Alt 或改成长按，右键要配修饰键或长按，左键要配修饰键。Esc 取消，Backspace 或框里的小叉清除；被别的程序占用的组合键会提示换一个）、排除名单（点“添加程序”从开着的程序里选或浏览 exe，点程序名去掉）。设置窗口和迷你任务栏一样是玻璃面板，拖标题栏移动，Tab / 方向键 / 空格也能操作。托盘右键菜单里也能直接开关这两项功能、开机自启和“以管理员身份运行”；左键单击托盘图标弹出迷你任务栏。

“自动检查更新”默认关闭；打开后每天到 GitHub Releases 查一次，有新版本时托盘弹出提示，点一下打开下载页面，不会自己下载或安装任何东西。不想常开的话，托盘右键菜单里的“检查更新”可以随时查一次。

设置保存在 `%APPDATA%\TaskbarPopup\settings.ini`，可以用记事本直接改，改完重启程序：

```ini
[General]
AutoHideOnFullscreen=1
LongPressPopup=1
LongPressMs=1000
PopupScale=100
ShowPinnedApps=1
ShowLevels=1
DebugLog=0
RunAsAdmin=0
CheckUpdates=0
KeepFloatsOnTop=1
GlassStyle=0
Theme=0
PopupHotkey=Ctrl+Alt+Z
PopupHotkeyHold=0
PopupHotkeyHoldMs=1000
PinHotkey=MouseMiddle
PinHotkeyHold=1
PinHotkeyHoldMs=800
ExcludeApps=notepad.exe;game.exe
```

`GlassStyle`：0 液态玻璃，1 毛玻璃；`Theme`：0 跟随系统，1 浅色，2 深色；`PopupHotkey`、`PinHotkey`：弹出迷你任务栏、固定小窗口的快捷键，空着就是不用；鼠标键写成 `MouseLeft` / `MouseRight` / `MouseMiddle` / `MouseBack` / `MouseForward`，单独的修饰键写成 `LCtrl`、`RShift`、`RAlt` 这样；后面加 `Hold` 的那项是 1 就长按触发，加 `HoldMs` 的是这个快捷键要按住多久（毫秒）。

**遇到问题**：在托盘右键菜单里打开“记录诊断日志”，复现一次，再点“打开诊断日志所在文件夹”，把 `debug.log` 发过来。平时不用开日志。

## 已知限制

- **管理员权限的程序和游戏里长按 Win 只会打开开始菜单**（比如任务管理器、带反作弊的游戏）：Windows 不把它们的按键交给普通权限的程序，遇到时托盘会提示一次。长按的快捷键、鼠标键和单独的 Ctrl / Shift / Alt 这类快捷键也一样（单按的键盘快捷键不受影响）。在托盘右键菜单勾选“以管理员身份运行”即可，勾选时弹一次 UAC，从迷你任务栏打开的应用仍是普通权限。
  - 同时开着开机自启的话，开机和之后的手动启动都走计划任务，不再弹 UAC（程序换了位置或从旧版本更新后，第一次启动还会弹一次）；没开开机自启时，每次启动都会弹 UAC。
- **Edge / Chrome 底边可能有一条约 2 像素的细线**：这是浏览器给自动隐藏的任务栏留的，外部改不了。
- **多块屏幕**：系统的自动隐藏对所有屏幕一起生效，所以一块屏幕上有最大化的窗口时，其他屏幕的任务栏也会变成自动隐藏（鼠标移到底边才弹出），那里最大化的窗口也会跟着铺满。
- **最大化时通知可能不弹出**：铺满屏幕的窗口可能被当成全屏程序。到 设置 → 系统 → 通知 → 自动打开勿扰模式，关掉“全屏模式下使用应用时”。
- **个别窗口铺不满**：少数程序拉伸后马上改回原样，试几次不成，这个窗口在前台时任务栏就照常显示；把窗口还原再最大化会重新尝试。
- **任务栏设置被锁住**（比如公司电脑用组策略禁止更改任务栏设置）：打不开自动隐藏，任务栏会照常显示。
- **独占全屏的老游戏**：迷你任务栏会被盖住，把游戏改成“无边框窗口”即可。
- **迷你任务栏的玻璃背景是弹出那一刻的画面**：后面播放的视频不会跟着动。设置窗口的玻璃会实时跟着变：拖动时跟着移动，后面画面变了（视频、别的窗口挪动）也会重画；画面一直不动时检查得慢一些，省电。拖动或背景在变的时候，系统截图和录屏里看不到设置窗口。这要 Windows 10 2004 及以上，更老的系统上设置窗口也只用打开那一刻的画面。
- **杀毒软件可能误报**：exe 没有数字签名，又用了低级键盘钩子（只用来判断是不是长按 Win 和设好的快捷键，不记录、不发送任何按键）和鼠标钩子（开着“小窗口留在上面”时判断双击了哪个小窗口、点没点全屏窗口；设了鼠标键的快捷键时认这个键），Windows 安全中心等可能把它当成可疑程序。代码全部开源，Release 里的 exe 由 GitHub Actions 从源码直接编译。被拦下时到 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录 里还原并允许，或者把程序所在的文件夹加入排除项。
- **强制结束本程序后任务栏没回来**：重新打开本程序就会恢复（藏起的桌面图标也会显示回来）；或者重启“Windows 资源管理器”，再到 设置 → 个性化 → 任务栏 → 任务栏行为 里关掉“自动隐藏任务栏”。

## 从源码编译

需要 C++17，在仓库根目录用下面任一种方式：

- **Visual Studio 2022**（装“使用 C++ 的桌面开发”）：在“x64 Native Tools Command Prompt”里运行 `cmake -B build -G "Visual Studio 17 2022" -A x64`，再 `cmake --build build --config Release`；也可以用 VS 直接打开仓库根目录，在配置下拉框的“管理配置...”里加一个 x64-Release 再生成。
- **MSYS2 / MinGW-w64**：`cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release`，再 `cmake --build build`。
- **Linux 交叉编译**（需要 `g++-mingw-w64-x86-64-posix`）：`sh build-mingw.sh`。

| `src/main.cpp` | 入口、托盘菜单、设置读写、开机自启 |

| `src/hook.cpp` | 键盘钩子：区分短按、长按 Win 和组合键；鼠标键、长按这类快捷键 |

| `src/glass.cpp` | 液态玻璃材质 |
| `src/float_windows.cpp` | 点全屏窗口时小窗口留在上面 |
| `src/hotkeys.cpp` | 快捷键：弹出迷你任务栏、固定小窗口 |

| `src/apps.cpp` | 打字筛选用的“所有应用”列表 |
| `src/pinned.cpp` | 读取任务栏的固定列表 |
| `src/app_menu.cpp` | 右键菜单：认出是哪个应用、跳转列表的最近项、以管理员身份运行 |

| `src/levels.cpp` | 音量和亮度（Core Audio、DDC/CI、WMI） |
| `src/elevation.cpp` | 以管理员身份运行 |
| `src/update.cpp` | 检查更新（默认关闭） |
| `src/settings_dialog.cpp` | 设置窗口 |
| `src/util.cpp` | 工具函数、诊断日志 |
| `src/version.h` | 版本号（自动构建按标签覆盖） |
