# TaskbarPopup：Win11 任务栏增强（C++ 版）

托盘常驻小程序，纯 Win32 + GDI+，单个 exe，不需要安装任何运行库。

1. **窗口最大化 / 全屏时隐藏任务栏，窗口铺满屏幕**：前台窗口一最大化（比如最大化的 Edge），任务栏就顺着屏幕底边滑下去，最大化的窗口同时往下铺满整块屏幕，两者是同一段动画。在它上面打开或切到普通窗口（比如从迷你任务栏打开一个应用）时，只要最大化的窗口还露在后面，任务栏就继续藏着；把最大化的窗口还原、最小化或关掉时，任务栏再滑回来，窗口等任务栏盖住底边后悄悄缩回原来的大小。
   Edge、Chrome、Claude 桌面端、VS Code 这类基于 Chromium / Electron 的程序，会把最大化的窗口强行改回“工作区”（屏幕减去任务栏）的大小，而工作区是资源管理器按任务栏算出来的，别的程序改了它也会被改回去。所以任务栏藏起来期间，本程序临时打开系统的“自动隐藏任务栏”，工作区这才真正变成整块屏幕，这些窗口自己就会铺满；同时把任务栏藏住，鼠标移到屏幕底边也不会弹出来。任务栏滑回来时再关掉自动隐藏，你原来的设置不变（本来就开着自动隐藏的话本程序不碰它）。
   打开 / 关闭自动隐藏时桌面可能按新的工作区重新排一次图标，本程序事先记下每个图标的位置，排完以后把挪了的摆回原位（桌面开着“自动排列图标”时不需要）。
2. **长按 Win 弹出迷你任务栏**：按住 Win 1 秒（可在设置里改），屏幕底部中央会弹上来一个液态玻璃质感的小任务栏：透出后面模糊的画面，边缘像透镜一样折射背景、带一点色散和高光，下面有柔和的阴影；背景偏亮时自动换成浅色玻璃配深色文字。前面是你固定在任务栏的应用，顺序和系统任务栏一致；后面是其它打开的窗口。任务栏露着时，迷你任务栏弹在它上面。
3. **音量和亮度调节条**：迷你任务栏下面一行，左边调音量（默认播放设备），右边调迷你任务栏所在那块屏幕的亮度。
4. **窗口缩略图**：鼠标在打开的窗口图标上停一下，上方会显示这个窗口的实时缩略图（和系统任务栏的预览一样），同一个程序开着好几个窗口时一眼就能认出来。用键盘选的时候也会显示。
5. **打字筛选**：迷你任务栏弹出后直接打字，只留下标题、名字或程序名里有这些字的窗口和固定应用，后面再列出开始菜单“所有应用”里匹配的程序（比如打 calc 找到计算器）。第一个结果自动选中，回车切过去或启动；Backspace 删字，Esc 先清空打的字、再按一次收起。
6. **排除名单**：有些程序最大化时不想藏任务栏，就在迷你任务栏里右键它的图标，勾选“最大化时不隐藏任务栏”；也可以在设置窗口里按每行一个程序名编辑。

短按 Win 仍然打开开始菜单，Win+E、Win+D、Win+Shift+S 等组合键都不受影响。

## 下载和运行

到本仓库的 [Releases](../../releases) 页面下载最新的 `TaskbarPopup.zip`，解压后双击 `TaskbarPopup.exe`，右下角托盘区会出现一个蓝色向上箭头图标。每次推送到 main 的自动构建结果也可以在 [Actions](../../actions) 里下载。

## 迷你任务栏操作

| 操作 | 效果 |
| --- | --- |
| 长按 Win | 弹出 / 收起 |
| 单击图标 | 切换到该窗口（点当前窗口则最小化，和系统任务栏一样）；固定的应用还没打开时直接启动 |
| Shift + 单击 | 固定的应用再开一个新窗口 |
| 右键单击运行中的图标 | 菜单：关闭这个窗口；同一程序开着好几个窗口时还可以一次全部关闭；“最大化时不隐藏任务栏” |
| 鼠标停在窗口图标上 | 显示窗口缩略图 |
| 直接打字 | 筛选窗口和应用，回车打开选中的；Backspace 删字，Esc 清空 |
| 中键单击图标 | 关闭该窗口；点在还没打开的固定应用上则启动它 |
| Delete | 关闭选中的窗口 |
| ← → 或 Tab，回车 / 空格 | 键盘选择并切换（Shift + 回车 = 新窗口；打字筛选时空格是要打的字） |
| 滚轮 | 图标多时左右滚动；鼠标在调节条上时调音量 / 亮度（一格 2%） |
| 拖动调节条 | 调音量 / 亮度，拖动时顶部一行显示百分比 |
| 单击喇叭 | 静音 / 取消静音 |
| 左侧 Windows 图标 | 打开开始菜单 |
| Esc / 点到别处 | 收起 |

图标下方的小横条：蓝色长条是当前窗口，短条表示已经打开，没有横条的是还没打开的固定应用。顶部一行显示鼠标所指或当前选中项的名称，右侧是时钟。

亮度：笔记本自带的屏幕用系统接口调；外接显示器通过 DDC/CI 调，需要显示器支持并在显示器自己的菜单里打开 DDC/CI（多数显示器默认开着）。都不支持时亮度条显示为灰色。

固定的应用直接读取系统任务栏的固定列表（`%APPDATA%\Microsoft\Internet Explorer\Quick Launch\User Pinned\TaskBar` 里的快捷方式，以及注册表里记录的商店应用）。在系统任务栏上固定 / 取消固定后，下次弹出就会跟着变。

## 设置

右键托盘图标 →“设置...”：

- 窗口最大化或全屏时隐藏任务栏，窗口铺满屏幕（开 / 关）
- 长按 Win 键弹出迷你任务栏（开 / 关）
- 长按时长：200 – 5000 毫秒，默认 1000
- 显示固定在任务栏的应用（开 / 关）
- 开机自动启动
- 最大化时不隐藏任务栏的程序：每行一个程序名（如 `notepad.exe`），也可以在迷你任务栏里右键运行中的程序来添加或去掉

设置保存在 `%APPDATA%\TaskbarPopup\settings.ini`，也可以直接改这个文件后重启程序：

```ini
[General]
AutoHideOnFullscreen=1
LongPressPopup=1
LongPressMs=1000
ShowPinnedApps=1
DebugLog=0
RunAsAdmin=0
ExcludeApps=notepad.exe;game.exe
```

这个文件按 UTF-16 保存，中文名字的程序也能正确记住；用记事本改完直接保存即可。旧版本留下的文件第一次启动时会自动转换。

托盘右键菜单里也能直接开关前两项、开机自启和“以管理员身份运行”；左键单击托盘图标会弹出迷你任务栏。

**诊断日志**：托盘右键菜单 →“记录诊断日志”。打开后会把隐藏 / 显示任务栏、打开 / 关闭自动隐藏、拉伸窗口、摆回桌面图标及其结果逐条记到 `%APPDATA%\TaskbarPopup\debug.log`，菜单里的“打开诊断日志所在文件夹”可以直接找到它。遇到问题时打开它、复现一次，再把这个文件发过来就能看出原因。平时不用开。

## 已知限制

- **管理员权限的程序和游戏**：前台是以管理员身份运行的程序（任务管理器、不少游戏、从管理员权限的 Steam 启动的游戏、带反作弊的游戏）时，Windows 不把按键交给普通权限的程序，长按 Win 会直接打开开始菜单。遇到这种情况本程序会在托盘弹一次提示。到托盘右键菜单勾选“以管理员身份运行（游戏里也能长按 Win）”即可：勾选时会弹一次 UAC 确认，之后开机自启改用最高权限的计划任务（开机不弹 UAC），从迷你任务栏打开的应用仍然以普通权限启动（资源管理器正在重启时会提示稍后再试，不会改用管理员权限启动）。把程序换了位置（比如解压了新版本）后，第一次启动会再弹一次 UAC，计划任务随之改成新的位置；从旧版本更新到这一版后第一次手动启动也会弹一次。取消勾选就恢复成普通权限运行。
- **自己定最大化尺寸的窗口**：极少数程序最大化时不按工作区摆放，或者拉伸后马上改回去。这类窗口在前台时任务栏照常显示（拉伸 3 次都不生效就放弃，直到把这个窗口还原再最大化才重新尝试），免得底下露出一条空白，也不会让任务栏反复上下伸缩。放大镜之类停靠在屏幕边上的工具栏会照样让开。
- **Edge / Chrome 底边可能有一条约 2 像素的细线**：系统开着自动隐藏任务栏时，Chromium 会在任务栏那条边上给它留 2 像素，好让鼠标碰到时把任务栏叫出来。这是浏览器自己的处理，外部改不了。
- **多块屏幕**：系统的“自动隐藏任务栏”对所有屏幕一起生效。一块屏上有最大化的窗口时，其它屏幕上的任务栏也会变成自动隐藏（鼠标移到那块屏底边会弹出来），那块屏上最大化的窗口也会跟着铺满。
- **按 Win 打开开始菜单**：任务栏藏着时打开开始菜单、通知中心或托盘溢出区，任务栏会先显示出来，关掉后再藏回去。
- **通知可能被当成“全屏”屏蔽**：铺满屏幕的最大化窗口在几何上和全屏程序一样。如果发现最大化时通知不弹出，到 设置 → 系统 → 通知 → 勿扰模式 → 自动打开勿扰模式，关掉“全屏模式下使用应用时”。
- **玻璃里透出的是弹出那一刻的画面**：迷你任务栏打开期间，后面的视频之类不会跟着动。
- **独占全屏游戏**：少数使用“独占全屏”模式的老游戏，任何窗口都无法盖在上面，迷你任务栏会弹出但看不到。把游戏改成“无边框窗口 / 窗口化全屏”即可。
- **资源管理器崩溃、卡住或重启**：本程序会等它恢复以后再决定藏不藏任务栏、关不关自动隐藏，不会把自动隐藏留在开着的状态，也不会因为去问一个卡住的资源管理器而跟着卡住。
- **自动隐藏任务栏被锁住时**（比如公司电脑用组策略禁止更改任务栏设置）：本程序打不开自动隐藏，试两次以后这个窗口在前台时就照常显示任务栏，不会让任务栏反复伸缩。
- **强制结束进程**：如果在任务管理器里直接结束本程序，任务栏可能停在隐藏状态，系统的“自动隐藏任务栏”也可能还开着。重新打开本程序即可自动恢复（是否由本程序打开的记在 settings.ini 的 `[State]` 里）；或者重启“Windows 资源管理器”让任务栏显示出来，再到 设置 → 个性化 → 任务栏 → 任务栏行为 里关掉“自动隐藏任务栏”。上一版改过的工作区，这一版启动时也会改回去。

## 从源码编译

需要 C++17。三种方式任选：

**Visual Studio 2022**（装“使用 C++ 的桌面开发”工作负载）：用 VS 打开本文件夹（CMake 项目），选 x64-Release 生成；或在“x64 Native Tools Command Prompt”里：

```bat
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

**MSYS2 / MinGW-w64**：

```sh
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

**Linux 交叉编译**（需要 `g++-mingw-w64-x86-64-posix`）：`sh build-mingw.sh`

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `src/main.cpp` | 入口、托盘图标和菜单、设置读写、开机自启动；启动、退出、崩溃时恢复任务栏 |
| `src/fullscreen.cpp` | 用 WinEvent 钩子盯着前台切换、最小化和前台进程的窗口位置变化（加上每 250 ms 复查），判断前台窗口是否最大化或铺满显示器；是的话藏起那块屏上的 `Shell_TrayWnd` / `Shell_SecondaryTrayWnd`，临时打开系统的自动隐藏（`SHAppBarMessage(ABM_SETSTATE)`）让工作区变成整块屏幕，并把最大化的窗口拉伸过去；离开时放回任务栏、关掉自动隐藏、把没跟着缩回去的窗口缩回去。自动隐藏是否由本程序打开记在 settings.ini 里，异常退出后下次启动时关回去 |
| `src/taskbar_anim.cpp` | 任务栏滑出 / 滑入动画，跑在单独的线程上：截一张任务栏的图放进置顶、点击穿透的分层窗口盖在原位，真任务栏在截图后面藏起来、打开自动隐藏、窗口在后面拉伸铺满，然后截图按屏幕刷新逐帧滑走；滑回时反过来，截图盖住原位后关掉自动隐藏、等真任务栏归位再淡出 |
| `src/desktop_icons.cpp` | 打开自动隐藏前通过 `IShellWindows` 找到桌面的 `IFolderView`，记下每个图标的位置；关掉以后等桌面重新排列完，把挪了的摆回去。跨进程调用在单独的线程上做 |
| `src/hook.cpp` | 低级键盘钩子，跑在单独的线程上。Win 按下先拦住：阈值内松开就补发一次 Win 单击，期间按了别的键就补发 Win+该键，超过阈值才算长按 |
| `src/popup.cpp` | 迷你任务栏：分层窗口，玻璃底板上用 GDI+ 画图标和文字，弹在鼠标所在屏幕的底部中央，带回弹的上滑动画和在图标间滑动的高亮块，按显示器 DPI 缩放；固定的应用和打开的窗口按 AppUserModelID 或程序路径对应起来 |
| `src/levels.cpp` | 音量（Core Audio，默认播放设备）和亮度（外接显示器走 DDC/CI，笔记本屏走 WMI，在后台线程上做，拖动时只执行最新的一次） |
| `src/glass.cpp` | 液态玻璃材质：截下弹窗后面的画面，模糊、提高饱和度；按圆角矩形的距离场算出边缘折射、色散、高光和阴影（只算一次），动画每帧只按位移取色 |
| `src/pinned.cpp` | 读取任务栏固定列表：快捷方式文件夹，加上注册表 `Taskband\Favorites`（决定顺序、包含商店应用），并取名称和图标 |
| `src/windows.cpp` | 按任务栏规则列出窗口（跳过工具窗口、其他虚拟桌面上的窗口等）并取图标 |
| `src/settings_dialog.cpp` | 设置窗口 |
| `src/util.cpp` | 公共工具函数、诊断日志 |
| `src/thumbnail.cpp` | 窗口缩略图：一个不抢焦点、点击穿透的小窗口，里面用 `DwmRegisterThumbnail` 显示窗口的实时画面 |
| `src/apps.cpp` | 打字筛选时搜索的所有应用：在后台线程上枚举 `shell:AppsFolder`（开始菜单“所有应用”，包括应用商店应用），缓存 5 分钟 |
| `src/elevation.cpp` | 以管理员身份运行：重新启动、最高权限的开机计划任务、以普通权限启动应用、前台程序权限更高时的提示 |
