# TaskbarPopup

Windows 11 任务栏增强：窗口最大化时藏起任务栏、让窗口铺满整块屏幕；长按 Win 弹出一个液态玻璃风格的迷你任务栏。托盘常驻，单个 exe，不用装运行库。

## 功能

- **最大化时隐藏任务栏**：窗口一最大化，任务栏就滑下去，窗口同时铺满整块屏幕；把它还原、最小化或关掉，任务栏再滑回来。在它上面打开别的窗口时任务栏继续藏着。
  实现上会临时打开系统的“自动隐藏任务栏”，任务栏回来时再关掉，你原来的设置不变。桌面图标如果因此被重新排列，会自动摆回原位。
- **长按 Win 弹出迷你任务栏**：按住 Win 1 秒（时长可改），屏幕底部中央弹出一个玻璃质感的小任务栏：前面是固定的应用（顺序和系统任务栏一致），后面是其它打开的窗口。短按 Win 照常打开开始菜单，Win 组合键不受影响。
- **音量和亮度**：迷你任务栏下面一行，左边调音量，右边调所在屏幕的亮度。
- **窗口缩略图**：鼠标停在窗口图标上，显示这个窗口的实时缩略图。
- **打字筛选**：弹出后直接打字，筛选窗口和固定的应用，还会列出开始菜单里匹配的程序（比如打 calc 找到计算器），回车打开。
- **排除名单**：不想让某个程序最大化时藏任务栏，就在迷你任务栏里右键它的图标，勾选“最大化时不隐藏任务栏”。

## 下载

到 [Releases](../../releases) 下载最新的 `TaskbarPopup.zip`，解压后运行 `TaskbarPopup.exe`，托盘区会出现一个蓝色向上箭头图标。每次推送的自动构建可以在 [Actions](../../actions) 里下载。

## 迷你任务栏操作

| 操作 | 效果 |
| --- | --- |
| 单击图标 | 切换到该窗口，点当前窗口则最小化；没打开的固定应用直接启动 |
| Shift + 单击 | 再开一个新窗口 |
| 右键运行中的图标 | 关闭这个窗口或同一程序的全部窗口；设置最大化时不隐藏任务栏 |
| 中键单击 / Delete | 关闭窗口 |
| ← → 或 Tab，回车 | 用键盘选择并打开 |
| 直接打字 | 筛选；Backspace 删字，Esc 先清空、再按一次收起 |
| 滚轮 | 图标多时左右滚动；在调节条上时调音量 / 亮度 |
| 单击喇叭 | 静音 / 取消静音 |
| 左侧 Windows 图标 | 打开开始菜单 |
| Esc / 点到别处 | 收起 |

图标下的蓝色长条是当前窗口，短条表示已经打开。外接显示器调亮度需要支持 DDC/CI（多数默认开着），不支持时亮度条是灰的。

## 设置

右键托盘图标 →“设置...”：开关上面两项主要功能、改长按时长（200 – 5000 毫秒）、开机自动启动、编辑排除名单（每行一个程序名，如 `notepad.exe`）。托盘右键菜单里也能直接开关这些，以及“以管理员身份运行”；左键单击托盘图标弹出迷你任务栏。

设置保存在 `%APPDATA%\TaskbarPopup\settings.ini`，可以用记事本直接改，改完重启程序：

```ini
[General]
AutoHideOnFullscreen=1
LongPressPopup=1
LongPressMs=1000
ShowPinnedApps=1
DebugLog=0
RunAsAdmin=0
ExcludeApps=notepad.exe;game.exe
```

**遇到问题**：在托盘右键菜单里打开“记录诊断日志”，复现一次，把 `%APPDATA%\TaskbarPopup\debug.log` 发过来。

## 已知限制

- **以管理员身份运行的程序和游戏里长按 Win 没反应**：Windows 不把它们的按键交给普通权限的程序。在托盘菜单勾选“以管理员身份运行”即可；开机自启会改用计划任务，不弹 UAC，从迷你任务栏打开的应用仍是普通权限。程序换了位置或者从旧版本更新后，第一次手动启动会弹一次 UAC。
- **Edge / Chrome 底边可能有一条约 2 像素的细线**：这是浏览器给自动隐藏的任务栏留的，外部改不了。
- **多块屏幕**：系统的自动隐藏对所有屏幕一起生效，一块屏上有最大化的窗口时，其它屏的任务栏也会变成自动隐藏。
- **最大化时通知不弹出**：铺满屏幕的窗口会被当成全屏程序。到 设置 → 系统 → 通知 → 自动打开勿扰模式，关掉“全屏模式下使用应用时”。
- **个别程序不肯铺满**：拉伸几次都被改回去的窗口，在前台时任务栏照常显示。
- **独占全屏的老游戏**：迷你任务栏会被盖住，把游戏改成“无边框窗口”即可。
- **玻璃背景是弹出那一刻的画面**：后面播放的视频不会跟着动。
- **强制结束后任务栏没回来**：重新打开本程序就会恢复；或者重启“Windows 资源管理器”，再到 设置 → 个性化 → 任务栏 → 任务栏行为 里关掉“自动隐藏任务栏”。

## 从源码编译

需要 C++17，三种方式任选：

- **Visual Studio 2022**（装“使用 C++ 的桌面开发”）：打开本文件夹（CMake 项目），选 x64-Release 生成。
- **MSYS2 / MinGW-w64**：`cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release`，再 `cmake --build build`。
- **Linux 交叉编译**（需要 `g++-mingw-w64-x86-64-posix`）：`sh build-mingw.sh`。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `src/main.cpp` | 入口、托盘菜单、设置读写、开机自启 |
| `src/fullscreen.cpp` | 判断最大化的窗口，藏起任务栏、开关自动隐藏、拉伸窗口 |
| `src/taskbar_anim.cpp` | 任务栏滑出 / 滑回的动画（单独线程） |
| `src/desktop_icons.cpp` | 记下并摆回桌面图标的位置 |
| `src/hook.cpp` | 键盘钩子：区分短按、长按 Win 和组合键 |
| `src/popup.cpp` | 迷你任务栏的绘制和操作 |
| `src/glass.cpp` | 液态玻璃材质 |
| `src/thumbnail.cpp` | 窗口缩略图（DWM） |
| `src/apps.cpp` | 打字筛选用的“所有应用”列表 |
| `src/pinned.cpp` | 读取任务栏的固定列表 |
| `src/windows.cpp` | 列出窗口、取图标 |
| `src/levels.cpp` | 音量和亮度（Core Audio、DDC/CI、WMI） |
| `src/elevation.cpp` | 以管理员身份运行 |
| `src/settings_dialog.cpp` | 设置窗口 |
| `src/util.cpp` | 工具函数、诊断日志 |
