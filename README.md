# TaskbarPopup

Windows 10/11 任务栏增强：窗口最大化时藏起任务栏、让窗口铺满整块屏幕；长按 Win 从屏幕底部弹出液态玻璃风格的迷你任务栏。单个 exe，不用装运行库。

功能演示视频：[哔哩哔哩](https://www.bilibili.com/video/BV1BLp963E7e/)

## 功能

### 最大化即全屏

窗口一最大化，任务栏就滑走，窗口铺满整块屏幕；还原、最小化或关掉后任务栏滑回来，桌面图标留在原处。

也可以在设置里打开“一直隐藏任务栏”（默认关闭）：没有窗口最大化时任务栏也藏着，鼠标碰到屏幕边上也不会弹出来，要用时长按 Win。

![最大化时任务栏滑走，窗口铺满整块屏幕](docs/demo/fullscreen.webp)

### 按程序决定藏不藏

在迷你任务栏里右键某个程序，勾选“最大化时不隐藏任务栏”，它最大化时任务栏照常显示。在设置里关掉“最大化或全屏时隐藏任务栏”后，这一项变成“最大化时隐藏任务栏”，只有勾了的程序最大化时才藏任务栏。

![勾上“最大化时不隐藏任务栏”的程序，最大化时任务栏照常显示](docs/demo/apps.webp)

### 长按 Win 弹出迷你任务栏

按住 Win 1 秒（时长可改），底部弹出迷你任务栏：固定的应用、打开的窗口、托盘里隐藏的图标、时间，还有音量、亮度调节和 Wi-Fi、蓝牙开关。鼠标停在窗口图标上显示实时缩略图。短按 Win 照常打开开始菜单。

![长按 Win，迷你任务栏从底部升起](docs/demo/popup.webp)

### 任务栏藏着时短按 Win

任务栏被藏起来时短按 Win，底部先升起一行迷你任务栏，再照常打开开始菜单，关掉开始菜单时一起收起。

![任务栏藏着时短按 Win，迷你任务栏和开始菜单一起出来](docs/demo/start.webp)

### 托盘图标

系统托盘里藏起来的图标也在迷你任务栏里，默认四个一组叠在一起，滚轮或 ← → 翻页。左键和在系统托盘里点一样；右键弹出菜单，选“程序菜单”打开程序自己的菜单。

![托盘里藏起来的图标，滚轮翻页，右键打开程序菜单](docs/demo/tray.webp)

### 音量、亮度、Wi-Fi 和蓝牙

拖动或滚轮调音量、亮度；单击 Wi-Fi、蓝牙按钮开关，右键弹出系统的网络列表、蓝牙设备列表。

![拖动调音量，单击开关 Wi-Fi，右键打开网络列表](docs/demo/quick.webp)

### 媒体、输入法和电量

时钟旁边显示正在播放的歌曲或视频：封面和歌名下面是暂停 / 播放，点封面展开上一首、下一首，再点收起；还有输入法的中 / 英，点一下切换；笔记本上再显示电量和是否在充电。不想要的在设置“状态和控制”页关掉，迷你任务栏放在底部和侧边时各显示哪些分开设（选“迷你任务栏在”底部或侧边再改），改的时候迷你任务栏会弹出来给你看效果；时钟也在那里，可以加上星期、秒，或者去掉日期。

### 新消息提醒

任务栏藏着时，程序在任务栏上闪烁（比如来了消息），屏幕底边中间亮起一道橙光，迷你任务栏里它的图标也变成橙色，切过去看一眼就灭。

### 鼠标停在屏幕边上弹出

在设置里打开后，任务栏藏着时鼠标在屏幕底边（迷你任务栏放在侧边时是那条边）停一下，迷你任务栏就出来，不抢当前窗口的焦点；没点它的话鼠标移开就收起。

### 打字筛选

弹出后直接打字，筛选窗口和固定的应用，开始菜单里的程序也能搜到，回车打开。

![直接打字筛选，开始菜单里的程序也能搜到](docs/demo/filter.webp)

### 右键菜单

和系统任务栏一样：最近打开的文件、再开一个、以管理员身份运行、打开文件所在的位置、关闭窗口。中键点图标直接关闭窗口，右键左侧的 Windows 图标打开 Win+X 菜单。

![右键菜单：最近文件、管理员运行、一键全关，中键关闭，Win+X 菜单](docs/demo/menu.webp)

### 小窗口留在上面

双击浮着的小窗口（或按快捷键），之后点全屏窗口它也不会被盖住。在设置里打开“固定的小窗口在所有窗口上面”（默认关），它就盖在所有窗口上面。

![双击小窗口，点全屏窗口时它也不会被盖住](docs/demo/pin.webp)

### 快捷键

可以设一个弹出迷你任务栏的快捷键和一个固定小窗口的快捷键，组合键、单个键、鼠标键都行，单按或长按触发。默认都没设。

![快捷键可以是组合键、单个键或鼠标键](docs/demo/hotkeys.webp)

### 外观

材质选液态玻璃或 Win11 原版（和系统一样的亚克力，底色浓、字清楚，细边框），颜色选跟随系统、浅色或深色。强调色默认跟随系统，也可以自己挑；迷你任务栏的底色也能单独选。圆角、透明度、图标大小和间距改了马上能预览；顶上的标题行可以关掉，窗口名字改在面板上方显示。

![液态玻璃、浅色 / 深色、透明度都能实时预览](docs/demo/appearance.webp)

### 编辑模式

弹出后按 F2 进入编辑模式，迷你任务栏怎么摆自己定：

- 拖上边改大小（50 – 200%），拖左右两头改长度（放在侧边时是里侧那条边和上下两头），双击边恢复；
- 拖托盘、媒体、输入法、电量、时钟换顺序，拖出面板就隐藏；音量亮度条、Wi-Fi 蓝牙按钮也能拖出去隐藏（放在底部和侧边时各记各的）；
- 拖窗口图标或空白处，把整个面板沿着屏幕边挪到任意位置，靠近正中和两头时会吸过去，双击恢复；
- 右键选显示哪些、恢复默认顺序和位置；回车或 Esc 完成。

### 外观方案和备份

在设置“方案和备份”页把现在的外观存成方案（最多 8 个），之后点一下就换上：材质、颜色、大小、位置和显示哪些模块一起换。“导出…”把全部设置存成一个文件，换电脑后“导入…”就都回来了。

### 位置和对齐

迷你任务栏可以放在底部，也可以竖着放在屏幕左侧或右侧；在底部时还能选跟随系统、居中、靠左、靠右，在编辑模式里还能拖到任意位置。

![迷你任务栏放在底部、左侧或右侧](docs/demo/side.webp)

## 下载

到 [Releases](../../releases) 下载最新的 `TaskbarPopup.zip`，解压后运行 `TaskbarPopup.exe`，托盘区会出现一个蓝色向上箭头图标：左键弹出迷你任务栏，右键打开菜单和“设置...”。

| 右键 / 菜单键 | 右键菜单 |

| Esc / 点到别处 | 收起 |

## 设置

右键托盘图标 →“设置...”，选项分成任务栏、迷你任务栏、状态和控制、大小和位置、外观、方案和备份、快捷键、启动和更新几类，点左边的导航切换（Ctrl+Tab 也行），Tab、方向键、空格也能操作。设置保存在 `%APPDATA%\TaskbarPopup\settings.ini`。

界面语言在“外观”里选（跟随系统、中文、English），选了马上换。

![设置分门别类，点左边切换，界面语言随时换](docs/demo/settings.webp)

**多块屏幕**：迷你任务栏默认弹在鼠标所在的屏幕上，可以在“迷你任务栏”页改成弹在前台窗口所在的屏幕上；系统设置成“任务栏应用显示在窗口所在的任务栏”时，只列这块屏幕上的窗口。打开“大小和位置”页的“每块屏幕分别设置位置和对齐”后，把设置窗口拖到哪块屏幕上，改的就是那块屏幕的位置和对齐。前台窗口最大化时，其他屏幕上也有最大化窗口的话，那些屏幕的任务栏一起藏着，在它们之间切换时任务栏不再来回伸缩。

“自动检查更新”默认关闭，打开后每天查一次 GitHub Releases，有新版只提醒，不会自己下载或安装。

**遇到问题**：在托盘右键菜单里打开“记录诊断日志”，复现一次，再点“打开诊断日志所在文件夹”，把 `debug.log` 发过来。

## 已知限制

- **管理员权限的程序和游戏里长按 Win 没反应**：Windows 不把它们的按键交给普通权限的程序。在托盘右键菜单勾选“以管理员身份运行”即可；同时开着开机自启的话，开机不弹 UAC。
- **Edge / Chrome 底边可能有约 2 像素的细线**：浏览器给自动隐藏的任务栏留的，外部改不了。
- **多块屏幕**：系统的自动隐藏对所有屏幕一起生效，有最大化窗口时，其他没有最大化窗口的屏幕上的任务栏也会暂时自动隐藏。
- **最大化时通知可能不弹出**：到 设置 → 系统 → 通知 → 自动打开勿扰模式，关掉“全屏模式下使用应用时”。
- **个别窗口铺不满**：这个窗口在前台时任务栏照常显示。
- **任务栏设置被锁住**（比如公司电脑的组策略）：任务栏照常显示。
- **独占全屏的老游戏**会盖住迷你任务栏，改成“无边框窗口”即可。
- **外接显示器调亮度**需要显示器支持并打开 DDC/CI，不支持时亮度条是灰的。
- **Wi-Fi / 蓝牙按钮是灰的**：网卡被硬件开关或设备管理器禁用了。电脑上没有的那个不显示。
- **媒体**：只显示能在系统音量浮窗里看到的播放（大多数浏览器和播放器都有）。
- **输入法中英文**：个别第三方输入法自己管中英文，显示可能不准、点了也切不过去，这时用输入法自己的快捷键。
- **托盘图标**靠 UI 自动化在系统托盘里代点，个别程序可能点不中，这时请开着诊断日志试一次。
- **迷你任务栏的玻璃背景**是弹出那一刻的画面，后面播放的视频不会跟着动。
- **杀毒软件可能误报**：exe 没有数字签名，又用了键盘和鼠标钩子（只用来认长按 Win 和快捷键，不记录、不发送任何按键）。Release 里的 exe 由 GitHub Actions 从源码编译，被拦下时到 Windows 安全中心 → 保护历史记录 里允许。
- **强制结束本程序后任务栏没回来**：重新打开本程序就会恢复。

## 从源码编译

需要 C++17，在仓库根目录运行：

- **Visual Studio 2022**：`cmake -B build -G "Visual Studio 17 2022" -A x64`，再 `cmake --build build --config Release`
- **MSYS2 / MinGW-w64**：`cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release`，再 `cmake --build build`
- **Linux 交叉编译**（需要 `g++-mingw-w64-x86-64-posix`）：`sh build-mingw.sh`
